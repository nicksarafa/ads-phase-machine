# Art direction

Appended to every image prompt so a batch reads as one campaign. Edit this and
the next render picks it up — no restart. Delete it and the machine falls back
to the built-in direction in `src/lib/brand.ts`.

Write it as instructions to an image model, not as prose about the brand.

---

Art direction: calm, premium, editorial. Natural light, real people at real
desks, shallow depth of field, generous negative space. Muted neutrals with a
single violet accent (#6868E8). Never stock-photo cheesy, never neon, never
sci-fi, no glowing brains, no robots, no circuit-board clichés.
